# Jeux-de-devinette
Un petit jeu de devinette en HTML, CSS et JavaScript pur, sans framework ni dépendance. L'ordinateur choisit un nombre secret et tu dois le trouver en un nombre limité d'essais, avec des indices à chaque tentative.  Ce projet est la version graphique d'un programme Python en console réalisé dans le cadre de mes cours de développement web et mobile.
